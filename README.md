Born from intense deep-tech research, Sanjay and Rishi fused raw hardware mastery with frontier artificial intelligence to construct an unstoppable, field-grade diagnostic engine that operates where standard technology dies: in connectivity-blind deep farmland.
🌟 THE INNOVATION AT A GLANCE
⚡ Sub-Second Edge Intelligence: Custom-trained INT8 MobileNet running directly on raw ESP32 PSRAM yields instant disease detection in under 450ms with 0% Internet Connection.
🧠 God-Mode Cloud Fallback: When complex or mutated leaf pathogens appear, the pipeline auto-escalates to Google Gemini 1.5 Flash Vision for multi-spectral agronomic analysis.
🎨 HSV Necrosis Surface Mapping: Real-time spatial pixel thresholding calculates exact tissue degradation and infected surface area percentages.
🔊 Localized Spatial Audio Guidance: Integrated hardware voice synthesis translates complex botanical prescriptions into instant spoken local dialects for low-literacy farmers.
💾 Epidemiological Telemetry Engine: Every diagnostic event records crop type, pathogen ID, confidence metric, timestamp, and spatial metrics to MicroSD JSON logs.
🛡️ Space-Grade SCERA Chassis: Encased in a custom 45° anti-glare optical shroud for precision focal positioning and zero lens distortion under direct sunlight.

📊 STAGE 1 (TINYML) VS STAGE 2 (GEMINI API)
Stage 1: Offline TinyML Edge Engine
Inference Latency: < 450 ms
Power Consumption: ~ 160 mA @ 3.3V
Connectivity Need: Zero (100% Standalone)
Model Size: 480 KB (INT8 Quantized MobileNet)
Diagnostic Scope: Top Regional Crop Pathologies
Output Detail: Class Label + Necrosis Severity Score
Stage 2: Gemini 1.5 Flash Cloud Gateway
Inference Latency: 1,200 ms – 2,500 ms (network dependent)
Power Consumption: ~ 280 mA @ 3.3V (Wi-Fi Peak)
Connectivity Need: Active Internet Link (Wi-Fi / Mobile Hotspot)
Model Size: Multi-Billion Parameter Foundation Model
Diagnostic Scope: Open-World (1,000+ Pathologies & Variants)
Output Detail: Comprehensive Text: Pathogen ID, Infection Stage, Organic Remedies, Prevention Protocols
🛠️ HARDWARE PINOUT MAPPING SPECS
GPIO 4: Ultra-Bright Optical Flash Array — Illumination Trigger (Active HIGH during capture)
GPIO 12: MicroSD Card MOSI — SPI Bus Data Out (Tri-stated during boot)
GPIO 13: MicroSD Card CS — SPI Chip Select (Active LOW)
GPIO 14: SSD1306 OLED SDA / SCK — Shared I2C / SPI Clock (Time-multiplexed)
GPIO 15: SSD1306 OLED SCL — I2C Clock 400kHz (External 4.7kΩ Pull-up)
GPIO 2: Button 1 (Crop Selector) — Digital Input (Active LOW Interrupt)
GPIO 0: Button 2 (Capture Trigger) — Digital Input / Boot (Active LOW Interrupt)
GPIO 1 / 3: DFPlayer Mini Audio TX/RX — Hardware UART 9600 Baud (Serial Telemetry Stream)
